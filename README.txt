

1. index.html
- Chứa khung HTML: header, main #app, footer.
- Chỉnh menu/header/footer tại đây.

2. style.css
- Chứa toàn bộ CSS giao diện.
- Chỉnh màu, kích thước, khoảng cách, card, responsive tại đây.

3. script.js
- Chứa dữ liệu bài viết và toàn bộ logic JavaScript.
- Muốn thêm bài viết: thêm một object mới vào mảng A.
- Muốn đổi màu nền ảnh tạm: chỉnh GRAD.
- Muốn thêm loại trải nghiệm: chỉnh TYPES và ICON/GRAD nếu cần.

LƯU Ý:
- Logo hiện vẫn dùng đường dẫn /_blob/... giống file gốc. Nếu chạy độc lập ngoài môi trường đã cung cấp logo này, hãy thay src của logo trong index.html bằng đường dẫn file logo thật, ví dụ images/logo.png.
- CSS và JavaScript đã được tách khỏi index.html; logic gốc được giữ nguyên.
